The official C# clients connect to ClickHouse over either HTTP or the native TCP protocol.
Both clients ship in the `ClickHouse.Driver` NuGet package.

## HTTP {#http}

The HTTP client provides the high-level, thread-safe `ClickHouseClient` API and the ADO.NET API
used by ORMs. It targets .NET 6.0 and newer and is recommended for most applications.

[Read the HTTP client documentation](/integrations/language-clients/csharp/http).

## Native TCP {#native-tcp}

The native TCP client provides the experimental `ClickHouseTcpClient` API, including columnar block
reads, native compression, pooled connections, and pinned sessions. It targets .NET 8.0 and newer.

[Read the native TCP client documentation](/integrations/language-clients/csharp/tcp).
