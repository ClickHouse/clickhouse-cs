* Fixed `Enum` type names whose members omit their ordinals, such as `Enum8('a', 'b')` or `Enum8('a' = 5, 'b')`, failing with `FormatException` in `InsertOptions.ColumnTypes`, in query parameter type hints, and in the native TCP client's type resolution. Such members now get the ordinals the server assigns. In such a definition, an ordinal outside the range of the type, or a label or an ordinal that two members share, is rejected, as on the server ([#727](https://github.com/ClickHouse/clickhouse-cs/issues/727)).
