* Added `ClickHouseDataReader.TryGetEnumOrdinal(int ordinal, out int value)` for reading the underlying integer ordinal of an `Enum8`/`Enum16` (or `Nullable(Enum...)`) column (issue #439). Enum columns materialize as their string label, so the standard numeric accessors (`GetInt32`, `GetByte`, …) throw `InvalidCastException` on them (unchanged — this matches ADO.NET's behavior for a string-backed column); the new method resolves the label to the underlying wire ordinal via the enum's value map. The ordinal reflects the raw wire value and is independent of a configured `IReadValueConverter` (which transforms the string label seen by `GetString`/`GetValue`, not the ordinal). It returns `false` for non-enum columns, `NULL` values, and values that are not a known label.
