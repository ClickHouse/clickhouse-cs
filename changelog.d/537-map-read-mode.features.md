* Added `MapReadMode` (connection string `MapReadMode=KeyValuePairs`, or `ClickHouseClientSettings.MapReadMode`), which reads `Map(K, V)` columns as `List<KeyValuePair<K, V>>` instead of `Dictionary<K, V>`. A ClickHouse map may repeat a key and a dictionary cannot, so the default representation silently drops pairs (issue #537). The new mode keeps every pair, in server order, wherever a map appears in a column's type tree — arrays, tuples, nested maps and `Dynamic` included. Such a list is also accepted on the write path, both for binary inserts and as a query parameter. The default stays `Dictionary`, so existing code is unaffected.
