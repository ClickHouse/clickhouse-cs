* **Binary inserts are now compressed with zstd instead of gzip by default.** `InsertOptions.Compressor` defaults to `ZstdCompressor.Default` (level 3) rather than `GZipCompressor.Default` (gzip, fastest). Unlike the `Accept-Encoding` the driver sends for responses, which a server may decline, a request body's `Content-Encoding` is a declaration — an intermediary that re-encodes request bodies and does not understand zstd fails the insert outright. ClickHouse accepts zstd request bodies on every supported version (verified back to 25.8 LTS); behind an unknown proxy tier, set `Compressor = GZipCompressor.Default` to keep the previous codec.
