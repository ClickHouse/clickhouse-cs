* **Query responses are now compressed with zstd instead of gzip by default.** The driver advertises `zstd, lz4, gzip, deflate`, and ClickHouse's fixed preference order resolves that to zstd. Bodies are decoded transparently as before, so no code change is needed — but the codec on the wire changes, and with it the balance between payload size, server CPU and the client-side decode, which the driver performs on the calling thread. That balance also depends on the server's `http_zlib_compression_level`. Set `AcceptEncoding = "lz4"` (or `"gzip"`, the previous default) on the settings, the connection string, or a single query to choose the codec yourself.
