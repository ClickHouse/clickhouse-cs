* Reduced allocations on the binary write path (issue #553). Writing an `Int128`/`UInt128`/`Int256`/`UInt256` value no longer allocates two temporary arrays per value, and a rectangular multidimensional array whose leaf is a fixed-width primitive behind a wire-transparent wrapper (`LowCardinality(Int32)`, `SimpleAggregateFunction(any, Int32)`, …) now takes the same blit fast path as a bare leaf instead of boxing every element. `Nullable(...)` leaves keep the per-element path. Output bytes are unchanged.
