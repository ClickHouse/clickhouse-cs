* Fixed the type parser building a self-referential node for an empty parameter list, such as the `Tuple()` column type that ClickHouse accepts and reports back in `system.columns`. Any traversal of that node recursed until the stack was exhausted, so reading or describing such a column — most widely `ClickHouseConnection.GetSchema("Columns")`, which parses every type on the server — terminated the process with an uncatchable `StackOverflowException`. `Tuple()` now parses to a tuple type with no elements and reads back as a tuple of length zero (issue #567).
