* **Faster multidimensional array binary inserts** (issue #367): rectangular multidimensional CLR arrays (`int[,]`, `double[,,]`, …) of fixed-width primitive leaves (`Int8/16/32/64`, `UInt8/16/32/64`, `Float32/64`, `Bool`) are now serialized by blitting each contiguous inner row in a single write, instead of boxing every element through `Array.GetValue(int[])`. This eliminates one allocation and one virtual dispatch per element on the binary write path (a `int[1000,1000]` insert previously boxed ~1M values). Output bytes are unchanged. Jagged shapes (`T[][]`), nullable/`LowCardinality`/wrapped leaves, `Int128`/`UInt128` (`BigInteger`-backed here), and big-endian hosts continue to use the existing per-element path. Purely internal; no API change.
