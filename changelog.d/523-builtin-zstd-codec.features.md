* Built-in ZSTD codec (`ZstdCompressor`; HTTP `Content-Encoding: zstd` plus the native-protocol block path), backed by a vendored copy of the MIT-licensed pure-managed `ZstdSharp` port, so it adds **no third-party or native runtime dependency** (see `ClickHouse.Driver.Common/Vendor/ZstdSharp`). Set `InsertOptions.Compressor = ZstdCompressor.Default` to compress an insert; the level is an `int` between `ZstdCompressor.MinLevel` and `ZstdCompressor.MaxLevel` (default 3).
