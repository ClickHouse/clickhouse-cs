* Native TCP client: added replica-aware routing for ClickHouse Cloud. Set `ReplicaTag` on `ClickHouseTcpClientOptions` (or `ReplicaTag=` in the connection string), on `ClickHouseTcpQueryOptions` for one operation, or on the new `ClickHouseTcpSessionOptions` for `OpenSessionAsync`. Connections with the same tag reach the same replica. The client sends the tag in the TLS server name as `<tag>.sticky.<host>`, so it needs TLS, and the tag must be one DNS label. See [Replica-aware routing](https://clickhouse.com/docs/integrations/language-clients/csharp/tcp#replica-aware-routing).
