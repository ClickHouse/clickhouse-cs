* Fixed a binary insert crashing the process with a stack overflow when a `Dynamic` column (or an unhinted `JSON` path in `JsonWriteMode.Binary`) gets a value of type exactly `System.Object`, also inside a collection. The insert now throws `ClickHouseBulkCopySerializationException`, the same as for other unsupported types ([#644](https://github.com/ClickHouse/clickhouse-cs/issues/644)).
