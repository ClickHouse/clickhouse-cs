* With an `IReadValueConverter` configured, `client.QueryAsync<T>(...)` applies it per column on the overload that matches how the column was read: `ConvertValue<T>`, with `T` the property type, for a column read without boxing, and the boxed `ConvertValue` for a composite one. Scalar columns previously went through the boxed overload, so a converter whose two overloads return different results for the same cell now gets the typed result there.
