* Native TCP client: added replica-aware routing for ClickHouse Cloud. Set `ReplicaTag` on `ClickHouseTcpClientOptions` (or in the connection string), or on the new `ClickHouseTcpSessionOptions` for `OpenSessionAsync`, and connections with the same tag reach the same replica. See [Replica-aware routing](https://clickhouse.com/docs/integrations/language-clients/csharp/tcp#replica-aware-routing).
