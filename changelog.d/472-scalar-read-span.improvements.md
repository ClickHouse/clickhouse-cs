* Faster scalar reads from query responses: the response stream wrappers now implement `Stream.Read(Span<byte>)` directly instead of falling through to the base implementation, which rents and copies through a pooled array on every call, and mid-stream exception detection now records from below the read buffer so it observes one read per buffer refill rather than one per value decoded. Behavior is unchanged, including the short-read contract and mid-stream exception detection.
