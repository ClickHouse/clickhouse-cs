* Fixed scalar `ClickHouseDecimal` query parameters without an explicit type: they were always sent as `Decimal128(9)`, so the server silently truncated digits after the 9th decimal place and rejected values with more than 29 integer digits. The driver now uses a type that holds the value, and throws `ArgumentOutOfRangeException` if it needs more than 76 digits. ([#637](https://github.com/ClickHouse/clickhouse-cs/issues/637))
