* Fixed binary inserts into a non-`Nullable` `Enum8`/`Enum16` column sending a value the enum does not declare, which made text reads of the row fail. A `null`, or a number that is not a declared ordinal, now fails the insert with a `ClickHouseBulkCopySerializationException` (inner `ArgumentException`). This includes a `null` into an enum that declares the ordinal `0`, which was stored as that member before (issue #718).
