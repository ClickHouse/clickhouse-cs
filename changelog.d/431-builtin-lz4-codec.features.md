* Built-in LZ4 codec for binary inserts (`Lz4Compressor`; HTTP `Content-Encoding: lz4` plus the native-protocol block path). LZ4 now ships **in the core driver with no third-party runtime dependency** — it is backed by a vendored, internalized copy of the MIT-licensed `K4os.Compression.LZ4` / `K4os.Hash.xxHash` libraries bundled inside the package (see `ClickHouse.Driver.Common/Vendor/K4os`). Set `InsertOptions.Compressor = Lz4Compressor.Default`; the level is selectable via the driver-owned `Lz4Level` enum (default `Lz4Level.Fast`, recommended for almost all inserts). LZ4 trades a lower compression ratio for much higher throughput than GZip/Brotli, favouring inserts where client CPU rather than bandwidth is the constraint, and it imposes the least decompression load on the ClickHouse server.
