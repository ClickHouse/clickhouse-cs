* Fixed reading and inserting a column with a named `Tuple` element of type `JSON`, such as `Tuple(x JSON)`, or a `Nested` element of type `JSON(...)`, which threw `ArgumentException: Unknown type`. A named `Tuple` element in a query parameter type hint can now use a type alias, such as `{p:Tuple(x DOUBLE PRECISION)}` ([#543](https://github.com/ClickHouse/clickhouse-cs/issues/543)).
